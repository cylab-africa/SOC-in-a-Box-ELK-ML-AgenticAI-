# as false positives when combined with internal-only traffic.
#
# NOTE: LOLBins and general-purpose tools are EXCLUDED:
#   shells (bash, sh, zsh), recon tools (grep, find, ps, whoami, id),
#   network tools (ip, ss, netstat, iptables, curl, wget, nmap),
#   languages (python, perl, ruby, node), remote access (ssh, scp),
#   privilege tools (sudo, su, chmod, chown), data tools (tar, git)
#   These are flagged by the anomaly detector for a reason.
